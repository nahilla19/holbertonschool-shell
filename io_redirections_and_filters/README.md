# I/O Redirections and Filters

- 0-hello_world: Prints "Hello, World" followed by a new line.
- 1-confused_smiley: Displays a confused smiley "(Ôo)'.
- 2-hellofile: Displays the contents of the /etc/passwd file using cat.
- 3-twofiles: Displays the contents of /etc/passwd and /etc/hosts using cat.
- 4-lastlines: Display the last 10 lines of /etc/passwd using tail.
- 5-firstlines: Displays the first 10 lines of /etc/passwd using head.
- 6-third_line: Displays the third line of the iacta file using head and tail.
- 7-file: Creates a file with a special name containing "Best School" followed by a newline.
- 8-cwd_state: Saves the output of ls -la to ls_cwd_content, overwriting the file if it exists.
- 9-duplicate_last_line: Duplicates the last line of the iacta file using tail and echo.
- 10-no_more_js: Deletes regular files ending in .js from the current directory and its subdirectories.
- 11-directories: Counts all directories and subdirectories, including hidden directories, from the current directory.
- 12-newest_files: Displays the 10 newest entries in the current directory, one per line.
- 13-unique: Displays words that appear exactly once, sorted alphabetically.
- 14-findthatword: Displays lines containing the pattern "root" from /etc/passwd.
- 15-countthatword: Counts the lines containing the pattern "bin" in /etc/passwd.
- 16-whatsnext: Displays lines containing "root" and the three lines following each match in /etc/passwd.
- 17-hidethisword: Displays lines in /etc/passwd that do not contain the pattern "bin".
- 18-letteronly: Displays lines from /etc/ssh/sshd_config that begin with a letter, including uppercase and lowercase letters.
- 19-AZ: Replaces every A with Z and every c with e in standard input.
- 20-hiago: Removes all c and C characters from input using tr.
